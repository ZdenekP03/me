Interactive animations

I am interested in interactive animations and exploring ways to push beyond the limitations of standard HTML elements and conventional UI components. I believe that interactive animations can convey complex information more clearly, while also enhancing ergonomics, visual rhetoric, and aesthetics.

Because of my interest in interactive animation, I decided to write a thesis on how interactive animations could improve programming language documentation. Long story short — I created a few interactive animations which hopefully display how asynchronous callbacks work in JS.

If you are interested, try to complete this quiz which I used as a way to measure how well interactive visualizations can actually transfer complex information.
